Welcome to CU Item Rescue

Here's how to get the most out of the platform

01

Lost something?

Before posting a lost item, search the main page first. Someone may have already found it and posted it. Use the search bar or filter by category to look for your item.

02

Found something?

Before posting a found item, check if the owner has already reported it as lost. Switch to the Lost filter and search for the item. If you find a match, contact the owner directly.

03

Posting an item

If no match is found, go ahead and post the item. Be as descriptive as possible — include the category, location, and a clear description. Choose how you want to be contacted.

04

Student Services

If you found an item and handed it to Student Services (Cafeteria Building, adjacent to the International Student Office), mark this when posting so the owner knows where to go.

05

Item recovered?

Once your item has been found or returned, go to My Dashboard and mark it as resolved. This removes it from the listing so others know it has been recovered.

06

Stay responsible

Only post items you have genuinely lost or found on campus. Keep your contact information accurate so others can reach you easily.
